# Поэтапный план: учебный магазин (команда team07)

Тема магазина: **ноутбуки**.

Принцип плана: каждый этап самодостаточен — после его выполнения магазин остаётся рабочим, и результат этапа можно пронаблюдать в браузере по конкретному сценарию проверки. Этапы идут от обязательного минимума к дополнительным задачам.

Ключ localStorage: `team07:cart:v1` (для избранного — `team07:favorites:v1`).

---

## Этап 0. Каркас и данные каталога

**Что делается**
- Определить тему и подобрать 6–8 товаров (ноутбуки: офисный ультрабук, игровой ноутбук, лёгкий ноут для учёбы, трансформер и т.п.). Каждому товару: `id`, название, цена в рублях (целая), категория, описание, картинка.
- Оформить данные как массив объектов `products` в начале [`app.js`](../app.js).
- Заменить стартовую разметку [`index.html`](../index.html) на структуру: шапка с названием магазина, секция «Каталог» (сетка карточек), секция «Корзина» (список + итог).
- Базовые стили в [`styles.css`](../styles.css): сетка карточек, читаемые шрифты и кнопки.

**Наблюдаемый результат**: страница магазина выглядит как магазин — шапка, карточки товаров с названиями и ценами в рублях. Кнопки пока ничего не делают.

---

## Этап 1. Каталог с кнопкой «Добавить» (обязательный минимум, ч. 1)

**Что делается**
- Рендер карточек из массива `products` в JS: название, цена «1 250 ₽», кнопка «Добавить».
- Товаров минимум 3 (лучше 6+ сразу — пригодится для фильтров и поиска).

**Проверка**: открыть страницу — все товары из массива отображаются, у каждого есть название, цена и кнопка «Добавить».

---

## Этап 2. Корзина: добавление, удаление, общая сумма (обязательный минимум целиком)

**Что делается**
- Состояние корзины в памяти: массив позиций `{ id, name, price }` (повторное добавление — отдельная строкой; вариант фиксируется в комментарии).
- Кнопка «Добавить» добавляет товар в список корзины.
- У каждой позиции корзины кнопка «Удалить».
- Отдельный блок «Итого: N ₽», пересчитываемый при каждом изменении.

**Проверка (эталонная из ТЗ)**:
1. Добавить товар за 100 ₽ и товар за 200 ₽ → итог 300 ₽.
2. Удалить первый → итог 200 ₽.
3. Удалить второй → корзина пуста, итог 0 ₽.

**После этого этапа обязательный минимум выполнен — можно показывать демо.**

---

## Этап 3. Сохранение корзины после перезагрузки (F3)

**Что делается**
- При любом изменении корзины сохранять её в `localStorage` под ключом `team07:cart:v1`.
- При загрузке страницы восстанавливать корзину из хранилища; если данных нет — пустая корзина.

**Проверка**: добавить 2 товара → перезагрузить страницу (F5) → корзина и итог те же. Удалить товар, перезагрузить — изменение сохранилось.

---

## Этап 4. Изменение количества в корзине (F2)

**Что делается**
- Переход от «каждая строка — отдельный товар» к позициям `{ id, name, price, qty }`.
- Кнопки «+» и «−» у каждой позиции (или поле ввода количества); при `qty = 1` кнопка «−» удаляет позицию.
- Итог = Σ (цена × количество).

**Проверка**: добавить товар → нажать «+» 2 раза → количество 3, итог утроился; «−» до единицы → дальнейшее нажатие удаляет строку и уменьшает итог.

---

## Этап 5. Картинки товаров с заглушкой (F1)

**Что делается**
- Положить картинки в `assets/`, подключить в карточках.
- Обработчик ошибки загрузки (`onerror` / событие `error`): вместо битой картинки показывается заглушка (например, `shop.svg` или текст-плейсхолдер) и подпись.

**Проверка**: все товары с картинками; временно указать несуществующий файл у одного товара — вместо битого изображения видна заглушка с подписью.

---

## Этап 6. Поиск по названию (F4)

**Что делается**
- Поле ввода «Поиск» над каталогом; фильтрация карточек по подстроке названия (регистронезависимо) на `input`.
- Пустое поле — показываются все товары. Если ничего не найдено — сообщение «Ничего не найдено».

**Проверка**: ввести часть названия → в каталоге остаются только совпадающие товары; очистить поле → весь каталог вернулся.

---

## Этап 7. Категории, фильтр и сортировка (F5, F6)

**Что делается**
- У товаров поле `category` (например: «Офисные», «Игровые», «Для учёбы», «Трансформеры»).
- Кнопки/селект категорий + кнопка «Сбросить фильтр».
- Селект сортировки: «по цене ↑» и «по цене ↓» (плюс вариант «без сортировки»).
- Поиск, фильтр и сортировка работают вместе (комбинируются как pipeline).

**Проверка**: выбрать категорию → остались только её товары; нажать «Сбросить» → каталог полный; выбрать сортировку → цены возрастают/убывают; поиск + категория вместе показывают пересечение.

---

## Этап 8. Промокод на скидку 10% (F7)

**Что делается**
- Поле «Промокод» и кнопка «Применить». Код, например, `LAPTOP10`.
- Итоговая сумма = базовая × 0.9, округление до целых рублей (300 ₽ → 270 ₽).
- Повторное применение того же кода не меняет сумму (флаг «промокод уже применён», не накопление процентов).
- Кнопка/ссылка «Отменить промокод». Состояние промокода сохраняется вместе с корзиной в `localStorage`.

**Проверка**: корзина на 300 ₽ → применить `LAPTOP10` → итог 270 ₽ → применить ещё раз → по-прежнему 270 ₽; удалить один товар → пересчёт со скидкой; перезагрузка страницы → скидка сохранилась.

---

## Этап 9. Избранное (F8)

**Что делается**
- Кнопка «♡ В избранное» на каждой карточке; состояние хранится в `team07:favorites:v1`.
- Переключатель «Каталог / Избранное» (вкладки): в режиме «Избранное» показываются только отмеченные товары; добавление в корзину работает из избранного тоже.

**Проверка**: отметить 2 товара сердечком → открыть вкладку «Избранное» → там только эти два; добавить один в корзину; перезагрузить страницу — избранное сохранилось.

---

## Этап 10. Мобильная версия и клавиатура (F9, F10)

**Что делается**
- Адаптивная вёрстка: сетка карточек через `auto-fill`/`minmax`, корзина корректно сжимается; проверка в DevTools на ширине 375 px.
- Доступность: все кнопки — настоящие `<button>`; корзина обновляется с `aria-live`/`role="status"`; проверка Tab/Enter — весь основной сценарий проходим с клавиатуры; подписи у полей (`<label>`).

**Проверка (телефон)**: сузить окно до ширины телефона → карточки перестраиваются в одну/две колонки, ничего не уезжает; добавить и удалить товар можно тапом.
**Проверка (клавиатура)**: только Tab + Enter — добавить два товара в корзину, изменить количество, удалить позицию; скринридер/`aria-live` озвучивает изменение суммы.

---

## Этап 11. Упаковка, публикация и финальное демо

**Что делается**
- `python3 main.py --pack` → проверить `shop.zip` в чистой папке (все функции работают из архива).
- Включить GitHub Pages (Settings → Pages → Source: GitHub Actions), push в `main`, дождаться зелёного workflow.
- Подготовить короткие сценарии проверки для каждой реализованной функции (из этого плана) в `README.md` или issue.
- Прогнать весь чек-лист демо по публичной ссылке.

**Проверка**: `shop.zip` распакован в новую папку — магазин работает; публичная ссылка открывается, корзина и промокод функционируют; ключ корзины в `localStorage` виден как `team07:cart:v1`.

## Порядок и приоритеты

| Этап | Содержание | Приоритет |
|------|-----------|-----------|
| 0–2 | Каталог + корзина + сумма | Обязательный минимум |
| 3–4 | localStorage, количество | Высокий (часто спрашивают на демо) |
| 5–7 | Картинки, поиск, фильтры, сортировка | Средний |
| 8–9 | Промокод, избранное | Средний |
| 10–11 | Мобильная версия, клавиатура, публикация | Желательный финал |

Правило: если какой-то дополнительный этап не успевается — пропускается целиком, предыдущий рабочий результат сохраняется и демонстрируется.
